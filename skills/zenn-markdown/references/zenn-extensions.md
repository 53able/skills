# Zenn 独自記法

## メッセージ（アドモニション）

```markdown
:::message
通常の補足メッセージ
:::

:::message alert
警告・注意
:::
```

- デフォルト: 黄色系
- `alert`: 赤系警告

## アコーディオン（details）

```markdown
:::details タイトル
折りたたみ本文
:::
```

### ネスト

外側の開始/終了に `:` を **1 つ追加**する:

```markdown
::::details 外側タイトル
:::message
内側メッセージ
:::
::::
```

## HTML コメント（非表示メモ）

```markdown
<!-- TODO: 追記 -->
```

- **1 行のみ**有効。改行を含む複数行コメントは非対応。

## 対応しない HTML

`<br>` 以外の HTML タグ（`<sup>` 等）は原則非対応。上付き・下付きは数式 `$a^2$` `$a_1$` を検討。
