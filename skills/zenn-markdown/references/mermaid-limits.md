# mermaid 制限（Zenn）

````markdown
```mermaid
graph TB
    A --> B
```
````

## 公式制限

| 制限 | 値 |
|------|-----|
| 1 ブロックあたり文字数 | **2000 文字以内** |
| フローチャートの `&` チェーン数 | **10 以下** |
| クリックイベント（interaction） | **無効**（設定しない） |

超過時は図の代わりに **エラーメッセージ** が表示される。

## 分割方針

1. 2000 文字超 → 図を **複数ブロック** に分割する。
2. `a --> b & c --> d` の `&` が多い → ノードを明示的に書き分ける。
3. クリックで詳細を見せたい → アコーディオン `:::details` に SVG 截图または説明文を入れる（mermaid の click は使わない）。

## 互換性

mermaid.js の破壊的変更で表示が変わる可能性あり。プレビューで必ず確認。
