# 等身大な表現リファイン手順

日本語の文章を、盛りすぎず、卑下しすぎず、書き手・対象・事実の実際の大きさに近い表現へ整える。

## 基本方針

1. **大きく見せない。** 実績、感情、価値、影響を根拠以上に拡大しない。
2. **小さく見せない。** 過剰な謙遜、自己防衛、曖昧な逃げで本来の価値を薄めない。
3. **実感に戻す。** 抽象的な美辞麗句を、観察、行動、変化、制約、迷いに置き換える。
4. **断定を調整する。** 事実、推測、願望、姿勢を混ぜない。
5. **声を借りない。** 広告、自己啓発、採用広報、AI文体の既成句を、書き手自身の言葉へ戻す。

## ワークフロー

1. **目的と読者を確認する。**
   - 文章の用途を特定する: エッセイ、プロフィール、商品説明、採用文、スピーチ、SNS投稿、振り返りなど。
   - 読者に残したい印象を一文で置く。
   - 事実確認が必要な主張は、リファイン対象ではなく `要確認` として分離する。

2. **元文を分解する。**
   - 各文を `事実`、`感情`、`解釈`、`願望`、`評価`、`呼びかけ` に分ける。
   - 根拠がある強い表現と、根拠が薄い強い表現を分ける。
   - 書き手の実体験から遠い語をマークする。

3. **過剰表現を検出する。**
   - 必要に応じて `python3 scripts/flag-overstatement.py <file>` を実行し、誇張・借り物語彙・曖昧な絶賛の候補を得る。
   - スクリプト結果は候補として扱い、文脈で判断する。
   - 詳細な観点が必要な場合は `references/rewrite-checklist.md` を読む。

4. **等身大へ置き換える。**
   - 巨大な名詞を、小さな行動や観察へ戻す。
   - 絶対表現を、範囲と条件が分かる表現へ戻す。
   - 美談を、具体的な経験、失敗、判断、試行錯誤へ戻す。
   - 自己卑下を、現在地・制約・次の一歩へ戻す。
   - 読者への過剰な直接呼びかけを控え、文章の対象と動詞を明確にする。

5. **温度を整える。**
   - 感情を消さず、温度を実際に近づける。
   - 強い感情は、強い形容詞ではなく、身体感覚、行動、具体場面で示す。
   - 価値提案は、壮大な約束ではなく、誰のどんな負担がどう軽くなるかで書く。

6. **差分を提示する。**
   - 短い依頼では、`Before / After / 変更意図` の順で返す。
   - 長い文章では、先に全体方針を3点以内で述べ、その後にリライト版を提示する。
   - 不確かな事実や確認できない実績は、本文に混ぜず `要確認` として列挙する。

## 置き換えパターン

| 避ける方向 | 等身大な方向 |
| --- | --- |
| 世界を変える | 目の前の具体的な不便を減らす |
| 革新的な体験 | これまで面倒だった手順が少し短くなる |
| 圧倒的な成長 | できる作業が一つ増えた |
| かけがえのない仲間 | 一緒に悩み、手を動かしてくれた人たち |
| まだまだ未熟ですが | できることは限られるが、ここまでは試した |
| すべての人に届けたい | まずは同じ困りごとを持つ人に届けたい |

## 出力形式

### 短文リファイン

```markdown
Before:
> {元文}

After:
> {等身大な表現}

変更意図:
- {何を削ったか}
- {何を具体化したか}
- {どの断定を調整したか}
```

### 長文リファイン

```markdown
## リファイン方針
- {方針1}
- {方針2}
- {方針3}

## リライト案
{本文}

## 主な変更
- {変更点}

## 要確認
- {事実確認が必要な主張。なければ省略}
```

## 判断基準

- 読後に「すごそう」より「その人・対象の輪郭が見える」が残る。
- 形容詞より、観察・行動・制約・選択が増えている。
- 事実以上の約束をしていない。
- 価値を過小評価していない。
- 元文の声を消さず、借り物の語だけを減らしている。

## Error Handling

- 元文が抽象的すぎる場合は、推測で具体化せず、質問候補を3つ以内で出す。
- 実績や数値が根拠不明の場合は、本文から外して `要確認` に置く。
- 意図的に誇張する広告コピーや詩の場合は、このスキルの適用範囲外として、目的に合う文体調整へ切り替える。
- 文章が長すぎて全体リライトが難しい場合は、最初に代表段落を1つリファインし、同じ規則を全体へ展開する提案を行う。
