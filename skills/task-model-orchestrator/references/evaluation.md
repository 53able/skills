# 最小比較（反復するタスクに限る）

1. 同じ難度帯の実タスク集合と受入基準を事前固定し、評価対象外のデータで割り当て・昇格閾値を決める。
2. 比較: 親による直接実行、低コスト固定、上位モデル固定、タスク別ルーティング＋検証＋昇格。計画専用モデルの効果を主張するときだけ、計画なし・同等計算量の比較も加える。
3. タスクごとに初回合格、最終受入、重大失敗、完了時間、モデル・入力/出力使用量、再試行回数、人手の修正時間を記録する。検証器の誤受理・誤棄却も、独立した標本レビューで測る。
4. 同じ受入条件と同じ許可範囲で比較し、事後的に失敗例を除かない。効果量とばらつきを報告し、十分な標本がなければ結論を保留する。
5. 料金は使用する契約と当日の公式価格表で計算する。サブスクリプションの利用制限は API 請求額と区別する。
