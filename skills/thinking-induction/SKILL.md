# 帰納法的思考

> **核心**: 複数サンプル → 共通点抽出 → 一般化

## 演繹との違い

| 観点 | 演繹 | 帰納 |
|------|------|------|
| 方向 | 一般 → 個別 | 個別 → 一般 |
| 結論 | 必然的 | 蓋然的（例外あり得る） |
| 強み | 論理的確実性 | 新しい知見の発見 |
| 弱み | 新知見を生まない | 例外で崩れる |

## 実行プロトコル

```
1. [サンプル収集]
   分析対象のデータ・事例を収集する
   - 十分な量を確保（最低5つ以上）
   - 偏りのない選定（成功例だけでなく失敗例も）

2. [観察・記録]
   各サンプルの特徴を観察・記録する
   - 定量的特徴: 数値、頻度、時間
   - 定性的特徴: 状態、パターン、構造

3. [共通点抽出]
   サンプル間の共通点を抽出する
   - 全てに共通するもの
   - 大多数に共通するもの
   - 特定条件下で共通するもの

4. [一般化]
   共通点から一般的な法則・パターンを導く
   - 「〜の場合、〜である傾向がある」
   - 確信度・適用範囲を明記

5. [反例チェック]
   導いた法則に当てはまらない例を探す
   - 反例があれば法則を修正
   - 適用範囲を限定
```

## 出力テンプレート

```markdown
## 帰納的分析

### サンプル一覧
| # | サンプル | 特徴1 | 特徴2 | 特徴3 |
|---|---------|-------|-------|-------|
| 1 | ... | ... | ... | ... |
| 2 | ... | ... | ... | ... |
| 3 | ... | ... | ... | ... |

### 抽出した共通点
1. [共通点1]: N件中M件に該当
2. [共通点2]: N件中M件に該当

### 導いた法則
> [一般化した法則・パターン]

- 確信度: [高/中/低]
- 適用範囲: [どの条件下で成立するか]

### 反例・例外
- [反例があれば記載]
- [法則が成立しない条件]

### 結論
[発見したパターンと、その活用方法]
```

## 併用パターン

| 併用する思考法 | 役割 |
|--------------|------|
| アブダクション | 仮説を立てる際の検証材料 |
| クリティカルシンキング | サンプル選定の偏りを検証 |
| MECE | サンプル収集の漏れを防ぐ |

## アンチパターン

| やりがち | 問題 | 対策 |
|---------|------|------|
| サンプル数が少ない | 偶然の一致を法則と誤認 | 最低5つ以上のサンプル |
| 成功例だけ見る | 生存者バイアス | 失敗例も同数収集 |
| 反例を無視 | 誤った一般化 | 反例チェックを必ず行う |
| 相関と因果を混同 | 誤った施策につながる | 「傾向がある」と表現 |

## 注意

**例外が現れると結論が崩れる**

帰納で導いた法則は「蓋然的」であり、絶対ではない。新しいデータが出てきたら、法則を更新する準備を常に持っておくこと。
