# メタ思考

> **核心**: 対象レベル ↔ メタレベルの往復

## 2つのレベル

```
メタレベル（上位）
├─ 何を考えるべきか？
├─ 評価基準は何か？
├─ 意味・目的は何か？
└─ 思考プロセス自体は適切か？

対象レベル（下位）
├─ 具体的な目標
├─ 具体的な計画
├─ 具体的な行動
└─ 具体的な成果物
```

**例:**

```
対象レベル: 「このバグをどう直すか」
    ↓ メタレベルに上昇
メタレベル: 「なぜこのバグが発生する構造になっているのか」
    ↓ 対象レベルに戻る
対象レベル: 「構造を直してバグが起きにくい設計に変える」
```

## 実行プロトコル

```
1. [対象レベル可視化]
   現在の問題・取り組みを言語化する
   - 何をしようとしているか
   - 何が問題か
   - どこで行き詰まっているか

2. [メタレベル上昇]
   一段上の視点から問いを立てる
   - 「そもそも何を考えるべきか？」
   - 「評価基準は何か？」
   - 「この問題の本質は何か？」

3. [視点切り替え]
   複数の視点から対象を見直す
   - 時間軸: 短期/長期
   - 立場: 自分/相手/第三者
   - 抽象度: 具体/抽象

4. [洞察の抽出]
   メタレベルで得た気づきを言語化
   - 見落としていた観点
   - 問題の再定義
   - 新しい評価基準

5. [対象レベルへ反映]
   洞察を具体的なアクションに落とす
   - 問題の再設定
   - アプローチの変更
   - 優先順位の見直し
```

## メタ質問集

| 状況 | メタ質問 |
|------|---------|
| 行き詰まり | 「この問題の本質は何か？」 |
| 議論の堂々巡り | 「何が論点なのか？」 |
| 優先順位の混乱 | 「何を基準に判断すべきか？」 |
| 成果が出ない | 「そもそもの目的は何だったか？」 |
| 複雑すぎる | 「一番大事なことは何か？」 |

## 併用パターン

| 併用する思考法 | 役割 |
|--------------|------|
| PAC思考 | 前提・仮定・結論の分離 |
| ロジカルシンキング | 洞察を構造化 |
| ディベート思考 | 異なる視点を対立させる |

## アンチパターン

| やりがち | 問題 | 対策 |
|---------|------|------|
| メタに上がりすぎ | 抽象的すぎて行動できない | 必ず対象レベルに戻る |
| 対象に留まりすぎ | 本質を見失う | 定期的にメタ質問を投げる |
| 視点切り替えの羅列 | 洞察につながらない | 「だから何？」を問う |

## 注意

**メタ思考は「逃げ」ではない**

「一歩引いて考える」は、問題から逃げることではない。より効果的に問題に取り組むために、視点を変えること。必ず対象レベルに戻って具体的なアクションにつなげる。
