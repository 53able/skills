# 図解レビュー・チェックリスト（100点ルーブリック）

図解を4カテゴリ・100点満点で自己採点する。**図形と文字列の整合性が最も重い40点**を占める。合計点だけでなく、各カテゴリを個別に満点にすることを目標にする。あるカテゴリの高得点で別カテゴリの失点を相殺してはならない。70点前後の状態を最終案にせず、必ず100点まで改訂を繰り返す。

各チェック項目は「満点 / 一部減点 / 大幅減点」で判断し、1つでも崩れていればそのカテゴリを満点にしない。

## カテゴリA: 図形と文字列の整合性（40点） — 最重要

- [ ] すべての要素が「図形1つ + ラベル1つ」の対で存在する。図形のない浮遊テキスト、ラベルのない図形がない。(10点)
- [ ] 図形の形状的な意味づけ（例: 矩形=アクター、円=概念、角丸矩形=プロセス）が図全体の全要素で例外なく一致している。同種の要素に別の形状を使っていない。(10点)
- [ ] コネクタの向きが、関係性ラベルの動詞が示す主語→目的語の方向と一致している。矢印の向きとラベルの意味が逆になっていない。(10点)
- [ ] ラベル文字列が図形の内側に収まっている。省略・改行・縮小によって元の意味が変わっていない。同じ要素を指すラベル表記が図の中で揺れていない（表記ゆれがない）。(10点)

このカテゴリで1項目でも「大幅減点」がある場合、他カテゴリのスタイリング調整より先にここを修正する。

## カテゴリB: 意味の正確性（25点）

- [ ] 主メッセージが1文で言える。(5点)
- [ ] エレメント、ラベル、注釈の役割が混ざっていない。(5点)
- [ ] 情報の欠落、誇張、因果の飛躍がない。ソースの主張を超えて創作していない。(10点)
- [ ] 同じ形・同じ色・同じ線種が図全体で同じ意味に使われている（意味の一貫性）。(5点)

## カテゴリC: 認知負荷とレイアウト（20点）

- [ ] 一画面または一枚で読ませる要素数が多すぎない。(5点)
- [ ] 近い関係の要素が近くに配置され、線の交差が少ない。(5点)
- [ ] グループ表現は枠・背景色・余白のいずれか一つの方法に絞られている（重ねがけしていない）。(5点)
- [ ] 補助要素（吹き出し・強調記号・アイコンなど）が主役の理解を邪魔していない。(5点)

## カテゴリD: 表記とスタイル一貫性（15点）

- [ ] ラベルは短い名詞または動詞句で、同じ粒度の言葉が並んでいる。(5点)
- [ ] 文字サイズと太さのルールが定義され、図全体で守られている（通常2種類まで）。(5点)
- [ ] 白抜き文字はコントラストが十分な場合のみ使われている。(3点)
- [ ] 図だけで誤読される箇所には短い注釈が添えられている。(2点)

## 採点の運用ルール

1. 初回採点は70点前後になりがちだと想定する。100点との差分をリスト化し、優先度の高いカテゴリAから修正する。
2. 修正のたびに全カテゴリを再採点する。1カテゴリだけ直すと他カテゴリが崩れることがある（例: 整合性修正でレイアウトが崩れる）。
3. 最終納品前に、合計100点かつ全カテゴリが個別に満点であることを確認する。100点に満たない場合は、納品物の「確認事項」に残課題として明記する。

## 制作プロセス（参考）

- 最初にラフ案を作っている。
- 1案だけで決めず、少なくとも別パターンを1つ検討している。
- 可能なら第三者に「何を表しているか」を説明してもらい、誤読箇所を直している。
