# 図解パターン・カタログ

## 基本分類
- データチャート: 定量的な数値比較。棒・線・散布図などを優先する。
- コンセプトチャート: 定性的な質、構造、因果、関係を表現する。本スキルの主対象。
- テーブル: 比較項目が多いときに使う。図解化しすぎると読みにくい場合は表を残す。

## 構成要素
- エレメント: 登場人物、概念、プロセス、状態など。テキストを丸や四角で囲み、存在を明確にする。
- コネクター: 線、矢印、双方向矢印。関係、流れ、因果、交換を示す。
- オプション: 吹き出し、強調記号、引き出し線、Good/Bad、目盛り。補助に限定する。
- グルーピング: 枠、背景色、区切り線、余白、ブラケット。近い要素をまとまりとして読ませる。

## 最小構成
1. テキストをエレメント化する。
2. エレメント間を線または矢印で結ぶ。
3. コネクターに短い動詞または名詞ラベルを付ける。

## エレメントだけの型
- 独立: 複数要素が並ぶだけ。項目列挙、選択肢、構成要素。
- 隣接: 横並び、縦並び。近さや同列性を示す。
- 包含: 大きな枠の中に小要素を入れる。カテゴリ、内訳、範囲。
- 重なり: 共通部分を示す。ベン図、共通点、衝突領域。
- 対比: 左右や上下に置き、違いを強調する。

## 2要素 + 1コネクターの型
- A → B: 作用、提案、依頼、変換、原因から結果。
- A ↔ B: 相互作用、取引、コミュニケーション。
- A -- B: 関連、接続、同時存在。
- A ≠ B: 対立、比較、差異。
- A → B + ラベル: 何をしているかを動詞で明示する。
- A → B + 注釈: 条件、前提、制約を補足する。
- A ⇢ B: 弱い影響、仮説、未確定の関係。

## 3要素以上の型
- 直列: A → B → C。手順、時間、変換プロセス。
- 分岐: A → B/C。条件分岐、選択肢、派生。
- 合流: A/B → C。統合、原因の合成、入力から成果。
- 循環: A → B → C → A。フィードバック、改善ループ、サイクル。

## 複数要素の型
- 階層: 上位概念から下位概念へ。組織、分類、構造。
- マトリクス: 2軸で分類。優先度、ポジショニング、比較。
- 中心放射: 中心テーマから周辺要素へ。マンダラート、要因整理。
- レイヤー: 層で表現。アーキテクチャ、成熟度、抽象度。
- タイムライン: 時間軸。ロードマップ、履歴、ステップ。

## 選択規則
- 「時間」「手順」「変化」が主題なら、直列またはタイムラインを選ぶ。
- 「原因」「結果」「影響」が主題なら、A → B、合流、分岐を選ぶ。
- 「分類」「構成」「内訳」が主題なら、階層、包含、テーブルを選ぶ。
- 「違い」「選択」「優先度」が主題なら、対比、マトリクス、テーブルを選ぶ。
- 「相互作用」「取引」「会話」が主題なら、双方向コネクターを選ぶ。
- 「関係が多すぎる」場合は、主メッセージに不要な線を削り、複数図に分割する。
