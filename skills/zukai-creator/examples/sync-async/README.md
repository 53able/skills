# 同期と非同期の進め方

問い：依頼の完了を待ってから次の作業を始めるか。

対比＋直列を選ぶ理由：二列の同じ位置で、同期の「完了を待つ」と非同期の「待たずに次の作業を始める」を比べられるためです。時間軸や速度差は表しません。非同期の通知時点は架空の入力で定めた一例です。

代替テキスト：同期の例では依頼し、完了を待ってから次の作業を始める。非同期の例では依頼開始後、待たずに次の作業を始め、作業中に完了通知を受け取る。矢印は順序を表す。
