# キャッシュのヒットとミス

問い：データの有無で処理はどう変わるか。

分岐を選ぶ理由：ヒットとミスの条件、ミス時の取得→保存→返却を一つの流れで追えるためです。処理時間や速度差は示しません。

代替テキスト：データ要求後、キャッシュの有無を確認する。ヒット時はキャッシュのデータを返す。ミス時は保存元から取得し、キャッシュに保存してから返す。

スキル同梱の `input.md` は架空の根拠、スキル同梱の `brief.json` は説明設計、スキル同梱の `diagram.mmd` は完成したMermaidソースです。スキル同梱の [diagram.svg](diagram.svg) は描画済みの完成図で、レンダラーを使わずに開けます。
