# 説明図の実例

すべて架空の説明用入力です。問い、入力の段落ID、主張と図中の要素の対応を確認してから描きます。

- スキル同梱の `cache-hit-miss/`：仕組みを条件分岐で説明するMermaid図。
- スキル同梱の `layers/`：構成と担当を包含＋レイヤーで説明するSVG図。
- スキル同梱の `sync-async/`：次の作業を始める条件を対比するSVG図。

## 境界の評価ケース

1. **単純列挙**：「持ち物は筆記具、ノート、水」。関係や変化の説明が不要なので文章の箇条書きを選ぶ。項目ごとの属性を比べるなら表を選ぶ。図を明示的に求められた場合のみ、最小限の図にする。
2. **根拠のない因果**：「利用者数と売上が増えた」。共に増えたことだけでは因果を示せない。二項目の併記を選び、利用者数→売上の因果矢印は描かない。原因の説明が目的なら根拠を確認する。
3. **情報不足**：「処理Aの後に処理Bがある」。順序を示す図は作れるが、開始条件や失敗時の挙動は未確定と記録する。仮定を置く場合は明記し、結論を左右する情報は質問する。

期待結果は図の必要性と根拠への忠実さの手動評価用です。学習効果を実証するテストではありません。各例の検証記録はスキル同梱の各 `README.md` に記載します。
