# Phase 1: Understand

> Design Docsの内容を正確に把握し、実装スコープを特定する

## 目標

1. Design Docsの要約を生成する
2. 実装範囲の境界を明確にする
3. 変更対象のパッケージ・ファイルを特定する

## 判断: 親エージェント vs サブエージェント

```
IF 単純（以下すべて該当）:
├─ Design Docsが1ファイル、かつ短い
├─ 影響範囲が明確
├─ コードベース調査が不要
└─ → 親エージェントで実行

IF 複雑（以下いずれか該当）:
├─ Design Docsが複数ファイルにまたがる
├─ 影響範囲の特定にコード探索が必要
├─ 既存実装との整合性確認が必要
└─ → Task ツールで explore サブエージェントを起動（下記参照）

### サブエージェント起動: explore

**Task ツール呼び出しパラメータ**:

```json
{
  "subagent_type": "explore",
  "description": "Design Docs理解とスコープ特定",
  "model": "fast",
  "prompt": "以下のDesign Docsを精読し、実装スコープを特定してください。\n\n【調査対象】\n- Design Docs: {design-docsのファイルパス}\n- 関連ディレクトリ: {影響が予想されるパッケージ}\n- 関連キーワード: {検索キーワード}\n\n【出力内容】\n\n#### Design Docs要約\n| 項目 | 内容 |\n|---|---|\n| 背景・課題 | [記述] |\n| ゴール | [記述] |\n| 主要概念 | [概念1], [概念2] |\n| 技術的決定 | [決定]: [理由] |\n\n#### 実装スコープ\n| カテゴリ | 内容 |\n|---|---|\n| IN SCOPE | [機能1], [機能2] |\n| OUT OF SCOPE | [機能1] |\n| 変更対象 | `packages/xxx` |\n| 新規作成 | `path/to/file.ts` |\n\n#### 関連ファイル一覧\n- [ファイルパス]: [役割]\n\n【調査の深さ】thoroughness: \"medium\""
}
```

| 変数 | 取得方法 |
|------|----------|
| `{design-docsのファイルパス}` | ユーザー入力またはGlobで探索 |
| `{影響が予想されるパッケージ}` | Design Docsから読み取り（不明なら省略） |
| `{検索キーワード}` | Design Docsの主要概念から抽出（不明なら省略） |

> 詳細プロンプトテンプレート: [../subagent-prompts/explore-design-docs.md](../subagent-prompts/explore-design-docs.md)
```

## 親エージェント実行時の手順

### Step 1: Design Docs理解

**考えるべきこと**:
1. **背景・課題**: なぜこの機能が必要なのか？
2. **ゴール**: 何を達成しようとしているのか？
3. **主要概念**: どのような概念・用語が登場するか？
4. **技術的決定**: どのような設計判断がなされているか？

**出力**:
```markdown
## Design Docs要約

### 背景・課題
[1-2文で課題を記述]

### ゴール
[達成すべき状態を記述]

### 主要概念
- [概念1]: [説明]
- [概念2]: [説明]

### 技術的決定
- [決定1]: [理由]
- [決定2]: [理由]
```

### Step 2: 実装スコープ特定

**考えるべきこと**:
1. **IN SCOPE**: 今回実装する範囲は何か？
2. **OUT OF SCOPE**: 今回実装しない範囲は何か？
3. **変更対象**: どのパッケージ・ファイルが変更されるか？
4. **新規作成**: どのファイルを新規作成するか？

**出力**:
```markdown
## 実装スコープ

### IN SCOPE
- [実装する機能1]
- [実装する機能2]

### OUT OF SCOPE
- [実装しない機能1]
- [実装しない機能2]

### 変更対象パッケージ
- `packages/xxx`: [変更概要]
- `packages/yyy`: [変更概要]

### 新規作成ファイル
- `path/to/new-file.ts`: [目的]
```
