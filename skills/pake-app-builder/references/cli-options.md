# Pake CLI オプションリファレンス

最新の全オプションは `npx pake-cli@latest --help` で確認すること。
以下は 2026-06 時点の安定版オプション一覧。

## 必須

| オプション | 説明                                       | 例                              |
|------------|--------------------------------------------|---------------------------------|
| `[url]`    | 変換対象の URL（第一引数・位置指定）       | `https://app.example.com`       |
| `--name`   | アプリ名（省略時はプロンプトで確認）       | `--name "MyApp"`                |

## ウィンドウ・外観

| オプション            | 説明                                   | デフォルト |
|-----------------------|----------------------------------------|------------|
| `--width`             | ウィンドウ幅（px）                     | `1200`     |
| `--height`            | ウィンドウ高さ（px）                   | `780`      |
| `--hide-title-bar`    | 没入型タイトルバー（macOS のみ）       | `false`    |
| `--fullscreen`        | フルスクリーンで起動                   | `false`    |
| `--resizable`         | ウィンドウリサイズを許可               | `true`     |

## アイコン

| オプション | 説明                                                       | 例                                     |
|------------|------------------------------------------------------------|----------------------------------------|
| `--icon`   | カスタムアイコンのパスまたは URL（省略時はサイトから自動取得） | `--icon /path/to/icon.icns`         |

対応フォーマット: `.icns`（macOS）、`.ico`（Windows）、`.png`（Linux）

## システム統合

| オプション             | 説明                                         |
|------------------------|----------------------------------------------|
| `--show-system-tray`   | システムトレイアイコンを有効化               |
| `--install`            | `/Applications` へ直接インストール（macOS のみ） |

## 出力形式

| オプション  | 説明                                                       |
|-------------|------------------------------------------------------------|
| `--targets` | Linux 出力形式を指定: `deb`, `appimage` など（Linux のみ） |

## デバッグ

| オプション | 説明                                   |
|------------|----------------------------------------|
| `--debug`  | ビルドしたアプリ内で DevTools を有効化 |

## 注意事項

- 出力ディレクトリ: Pake はデフォルトでカレントディレクトリに成果物を配置する。`~/Downloads` に出力するには `cd ~/Downloads` してから `npx pake-cli` を実行すること。
- 初回ビルド: Rust ツールチェーンのダウンロードを含むため 5〜10 分かかる場合がある。
- 2 回目以降: Rust キャッシュにより 1〜3 分程度に短縮される。
- 常に最新版を利用: `npx pake-cli@latest`（`@latest` を省略すると npm キャッシュの古いバージョンが使われる可能性がある）。
