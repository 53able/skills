# 読まれる文章：マインドセットと戦術（ソース要旨）

一次エッセイの論旨を手順向けに再編したメモ。引用ではなく要約・再構成。

## 前提マインドセット

- **読まれない前提** — 大量投稿のフィードでは原稿はすぐ埋もれる。「選んでもらう努力」をしていないなら読まれないのは当然、と捉える。
- **届けるまでが仕事** — 「書いて終わり」ではなく、読者に届くまでが書き手の責務。
- **クリックが先** — 紙のようにページをめくってもらえる前提は Web では弱い。クリックされなければ本文は存在しないのに等しい。
- **コミュニケーション** — 文章は声の会話が文字に移ったもの。反応（いいね・コメント等）がゼロに近いなら一方的で、対話としては低評価とみなしてよい、という厳しさで振り返る。
- **独り言の罠** — モニタ前に人がいないと独り言になる。「聞いてもらう」「向こうに生身の人がいる」と置く。
- **時間は命** — 読了は読者の時間を奪う行為。だから **何を書かないか** が何を書くかより重要になりがち。圧縮は敬意の表れ。
- **血のメタファー** — 技巧の「かっこよさ」より、さらけ出しと熱量（エッセイでは「怨念」レベルと表現）。ただし **さらけ出しだけでは点数にならない** のはインプット不足が原因、という自己分析がある。
- **書かずにはいられないもの** — 最終的に心を掴むのは、抑制できないテーマに近い。

## 戦術（優先順・配分のヒント）

| 領域 | 内容 |
|------|------|
| タイトル | 努力の大半を寄せる（例として「9割」という比喩）。クリック動機が弱いと本文は読まれない。 |
| 本文の軸 | **読者にとってのメリット**。書き手が決めるのではなく、読者の知りたいこと・疑問に答える。 |
| インプット | アウトプットの質が低いときは量が足りない、という判断軸。「8倍」などの経験則に触れている。本を読むときは著者が読者をどう説得しているかを観察する（説得＝黙らせることではなく、一緒に考えてもらうこと）。 |
| 読者リサーチ | 「誰に向けて書くか」で「何を書くか」が変わる。同じテーマでもペルソナ別に骨子が変わる例がある。 |
| 構成 | 目安として **リサーチ7・構成2・執筆1**。構成案では **(1) 誰に何を伝えるか (2) 伝えた結果どうなってほしいか** に集中。PREP 等の型に思考停止しない。 |
| ゆるい構成 | 執筆は旅行の歩き方に似る。最初から最後まで固定しない選択肢もある。**筆が滑ったとき** に面白さが出る、という感覚。 |
| 完成 | こだわりすぎると終わらない。**諦めの線引きで完成**させる（プロは完成が仕事、という教えの紹介）。 |
| 圧縮・推敲 | 初稿後に削る。長さは読了・末尾の CTA（フォロー等）まで届かない原因になりうる、という観察。 |
| 寝かせ | 一晩置いて **他人として** 読み、拙い所を直してから掲載。 |
| 外部校正 | 自分の日本語は伝わっていると過信しがち。**第三者添削**の価値を推奨している。 |

## 注意

- プラットフォーム（note）の閲覧数や UI に依存する話も含まれるが、**フィード型の Web 長文**一般に転用できる部分として抽出している。
- 「タイトル9割」は比喩。ジャンル（手順書・ドキュメント等）ではタイトル比重が下がる場合がある。エージェントは文脈で調整する。
