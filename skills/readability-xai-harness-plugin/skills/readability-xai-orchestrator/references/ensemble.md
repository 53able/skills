# Faithful Evaluator アンサンブル（任意）

論文（Fig.6）では、5つの LLM で Faithful Evaluator を独立実行し、抽出辞書を**多数決**で統合して誤抽出を減らす。

## テキスト版への移植

1. 同一草案に対し、**異なるモデルまたは同一モデルで温度0の複数回**で主張抽出を行う。
2. 主張のキー（短いパラフレーズ）集合について、**過半数のキー集合**を採用。
3. rank/sign/value の代わり、各主張について `supported/contradiction/...` の票を集計し、タイは先出しルール（論文と同様）。

## いつ使うか

- ソースが長く、Evalutor の `low_confidence_spans` が多いとき
- ナラティブが曖昧でランキング解釈が割れるとき
