# 論理整合性レビュー・チェックリスト

出力前に全項目を確認する。

## 論点
- [ ] 文章が答えようとしている主論点を一文で示した。
- [ ] 主論点と副論点を混同していない。
- [ ] 対象、判断軸、範囲、読者行動の曖昧さを確認した。

## 情報
- [ ] 事実、定義、因果、比較、価値判断、提案を区別した。
- [ ] 結論に必要だが不足している情報を示した。
- [ ] 外部事実を検証していない場合は未検証と明記した。

## 推論
- [ ] 演繹、帰納、アブダクションのどの型で推論しているか確認した。
- [ ] 飛躍、論点ずれ、過度な一般化、相関と因果の混同を確認した。
- [ ] 反例または代替仮説が無視されていないか確認した。

## 構造
- [ ] 最終結論と主要根拠をピラミッド構造で整理した。
- [ ] Why So? で上位主張に下位根拠が答えているか確認した。
- [ ] So What? で下位根拠から上位主張が導けるか確認した。
- [ ] 同階層の根拠をMECE観点で確認した。

## 指摘
- [ ] 各指摘に重大度を付けた。
- [ ] 「根拠不足」と「論理破綻」を区別した。
- [ ] 致命的または重大な指摘には具体的な修正方針を付けた。
- [ ] 文章の意図を勝手に変える修正を避けた。
