## スポットチェック

- [ ] 冒頭セクションまたはタイトルがMarkdownに含まれている。
- [ ] 中盤の見出しまたは本文が少なくとも1つMarkdownに含まれている。
- [ ] 末尾セクション、参考文献、付録が存在する場合、Markdownに含まれている。
- [ ] タスク上重要な表または図を要手動確認として記録した。
